# Start Product Workflow

## 正式 MVP 第一阶段启动命令

老板正式开始做网站时，第一条需求必须是：

```text
新需求：启动同城搭子网站 MVP 第一阶段，请项目总管先给我产品计划、页面结构、多 Agent 分工和执行建议，先不要写代码，等我批准后再执行。
```

## 项目总管处理规则

收到这类正式产品需求后：

1. 只进入 `planning_only`。
2. 不直接改业务页面。
3. 不创建 Worker/Codex 执行任务。
4. 输出产品目标、MVP 范围、用户角色、页面清单、核心流程、多 Agent 分工、执行批次建议、风险和待老板确认事项。
5. 等老板发送 `总管 批准执行` 后才分发 Worker/Codex。
6. 如果老板说 `先不要写代码`，必须严格只规划。

## 执行前检查

开始真实网站开发前，老板应先发送：

```text
新需求：系统自检
```

如果自检提示分支、暂停状态或 Worker 防护异常，先处理异常，不进入开发。
