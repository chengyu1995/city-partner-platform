# 同城搭子网站 MVP 第一阶段状态文案

## 文档状态

- 阶段：BATCH-P2
- 性质：状态文案文档，不写 UI 代码
- 适用范围：首页、搭子列表页、发布搭子页及后续详情页参考
- 状态边界：只定义文案，不实现接口、数据库、审核后台或错误监控

## 状态文案原则

- 说明发生了什么、用户可以做什么、系统当前不能承诺什么。
- 空状态给下一步，错误状态给重试或返回，成功状态给结果边界。
- 不把待审核写成已公开，不把本地草稿写成云端保存。
- 不使用技术错误码直接面对普通用户。

## 空状态文案

| 场景 | 标题 | 说明 | 行动 |
| --- | --- | --- | --- |
| 首页无搭子预览 | 还没有可展示的搭子需求 | 可以先从发布一个需求开始，后续再展示更多同城内容。 | 发布搭子需求 |
| 列表无任何数据 | 暂时还没有搭子需求 | MVP 第一阶段可以先发布草稿或待审核需求。 | 去发布 |
| 当前城市无数据 | 这个城市暂时还没有搭子需求 | 可以切换城市看看，或先发布一条本地需求。 | 换个城市 / 去发布 |
| 当前分类无数据 | 这个分类暂时还没人发 | 可以换个分类，或把你的计划先发出来。 | 换个分类 / 去发布 |
| 草稿为空 | 还没有本地草稿 | 你保存过的发布内容会出现在这里，换设备可能无法同步。 | 新建草稿 |

## 错误状态文案

| 场景 | 标题 | 说明 | 行动 |
| --- | --- | --- | --- |
| 列表加载失败 | 暂时加载失败 | 可能是网络或服务暂时不可用，可以稍后再试。 | 重新加载 |
| 筛选结果失败 | 筛选结果没加载出来 | 当前筛选条件暂时无法刷新，可以重试或清空筛选。 | 重试 / 清空筛选 |
| 发布提交失败 | 提交失败 | 内容还没有进入待审核，请检查网络后重试。 | 重新提交 |
| 草稿保存失败 | 草稿没有保存成功 | 当前设备可能无法写入本地草稿，请先保留填写内容。 | 再试一次 |
| 表单校验失败 | 还有必填信息没填 | 请补充城市、分类、标题、时间、地点、人数和联系方式。 | 回到表单 |
| 联系方式格式不清楚 | 联系方式需要再确认 | 请填写能让审核人员理解的联系方式类型和内容。 | 修改联系方式 |

## 成功状态文案

| 场景 | 标题 | 说明 | 行动 |
| --- | --- | --- | --- |
| 保存草稿成功 | 已保存为本地草稿 | 草稿只保存在当前设备或当前浏览环境，后续可以继续编辑。 | 继续编辑 / 返回列表 |
| 提交待审核成功 | 已提交待审核 | 这条需求还不会直接公开，审核和联系方式展示策略会在后续批次确认。 | 返回列表 |
| 筛选成功 | 已更新筛选结果 | 当前结果按你选择的城市和分类展示。 | 继续浏览 |
| 表单重置成功 | 已清空表单 | 可以重新填写一条新的搭子需求。 | 重新填写 |

## 发布状态文案

| 状态值 | 展示文案 | 用户理解 |
| --- | --- | --- |
| `draft` | 草稿 | 只在本地保存，尚未提交 |
| `pending_review` | 待审核 | 已提交，但还没有公开 |
| `published` | 已发布 | 后续批次公开展示时使用 |
| `rejected` | 未通过 | 后续审核功能实现后使用 |
| `ended` | 已结束 | 活动时间已过或需求关闭 |

## 安全与边界提示

- 发布前提示：请不要填写身份证号、银行卡号、密码等敏感信息。
- 联系方式提示：联系方式展示策略不在本批实现，后续需要老板单独批准。
- 审核提示：提交待审核不代表已经公开，也不代表平台完成安全背书。
- 数据提示：本地草稿可能只保存在当前设备或浏览器环境。

## BATCH-P3 建议

- UI 实现时把状态文案统一放在可复用常量或页面附近，避免不同页面表达不一致。
- 空状态应提供清晰行动入口，但不要用弹窗打断浏览。
- 错误状态先做用户可理解表达，技术日志和错误码后续再设计。
