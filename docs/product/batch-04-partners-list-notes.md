# BATCH-04 搭子列表页 MVP 说明

## 本次范围

- 实现 `/partners` 搭子列表页 MVP。
- 支持通过 URL 参数读取 `city` 和 `category`。
- 使用页面内静态 mock 数据展示搭子卡片，不接真实后端。
- 保留移动端优先布局，并兼容桌面端双列卡片。

## 筛选能力

- `city`：按城市精确筛选，例如 `/partners?city=广州`。
- `category`：按分类精确筛选，例如 `/partners?category=旅游搭子`。
- 兼容首页可能传入的短分类值，例如 `旅游` 会归一化为 `旅游搭子`。

## 页面模块

- 页面标题：找同城搭子。
- 搜索 / 筛选区域：城市输入和分类下拉。
- 城市筛选入口：广州、深圳、杭州、上海、北京、成都。
- 分类筛选入口：旅游搭子、K 歌搭子、学习搭子、摩友搭子、钓友搭子。
- 搭子卡片列表：标题、城市、分类、时间或活跃状态、描述、发起人、按钮。
- 空状态：无匹配结果时展示引导。
- 安全提示：线下安全、不提前转账、首次公共场所见面。

## 未包含

- 不接真实数据库。
- 不执行 SQL。
- 不修改 `.env`。
- 不接支付、私信或推荐算法。
