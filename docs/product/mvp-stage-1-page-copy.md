# 同城搭子网站 MVP 第一阶段页面文案

## 文档状态

- 阶段：BATCH-P2
- 性质：页面文案文档，不写 UI 代码
- 适用页面：首页 `/`、搭子列表页 `/partners`、发布搭子页 `/post`
- 文案边界：只定义 MVP 第一阶段可用文案，不承诺真实匹配、即时公开或平台担保

## 文案语气

- 年轻、直接、轻社交，不像后台系统。
- 用“找搭子”“一起”“同城”这类低门槛表达。
- 避免夸大安全性、审核能力、匹配效率。
- 对发布结果保持克制：保存草稿、提交待审核，不写“发布成功并公开”。

## 首页文案

### 首屏定位

- 页面标题：同城找搭子，一起吃饭、运动、学习、出游
- 副标题：先从惠州、广州、深圳、上海开始，看看附近有没有合拍的人。
- 主按钮：去找搭子
- 次按钮：发布搭子需求

### 城市入口

- 模块标题：先选城市
- 模块说明：首批开放 4 个城市，后续可以继续扩展。
- 城市选项：惠州、广州、深圳、上海

### 分类入口

- 模块标题：你想找哪种搭子？
- 模块说明：按兴趣先筛一遍，更快找到合适的人。
- 分类选项：
  - 饭搭子：约饭、探店、下班吃点好的
  - 运动搭子：跑步、羽毛球、健身、球类
  - 学习搭子：自习、备考、读书、技能学习
  - 出游搭子：周边游、城市散步、短途旅行
  - K 歌搭子：KTV、清吧唱歌、练歌
  - 摩友搭子：骑行、路线、短途摩旅
  - 钓友搭子：野钓、黑坑、周末钓鱼

### 搭子预览

- 模块标题：最近有人在找
- 模块说明：先看一眼需求，合适再进入列表。
- 卡片按钮：查看详情
- 空预览提示：暂时还没有可展示的搭子需求，可以先发布一个。

### 发布引导

- 模块标题：没有合适的？自己发一个
- 模块说明：填写后先保存为本地草稿或进入待审核，不会直接公开联系方式。
- 按钮：去发布

- 页面标题：同城搭子

## 发布搭子页文案

### 页面头部

- 页面标题：发布搭子需求
- 页面说明：先填写基础信息，MVP 第一阶段会保存为本地草稿或进入待审核。

### 表单字段

| 字段 | Label | Placeholder / Help |
| --- | --- | --- |
| 城市 | 城市 | 选择或填写城市，例如惠州、广州、深圳、上海 |
| 分类 | 分类 | 选择你想找的搭子类型 |
| 标题 | 标题 | 例如：周六下午找羽毛球搭子 |
| 时间 | 时间 | 写清楚日期和大概时段 |
| 地点 | 地点 | 例如商圈、地标、球馆或集合点 |
| 期望人数 | 期望人数 | 包含自己在内的总人数 |
| 需求说明 | 需求说明 | 说清楚活动内容、节奏和希望对方了解的信息 |
| 适合人群 | 适合人群 | 可选，例如新手友好、女生优先、同校同区等 |
| 预算说明 | 预算说明 | 可选，例如 AA、免费、预计人均 |
| 注意事项 | 注意事项 | 可选，例如装备、迟到、天气、路线风险 |
| 昵称 | 怎么称呼你 | 用于草稿或审核展示 |
| 联系方式类型 | 联系方式类型 | 微信、手机号或其他方式 |
| 联系方式内容 | 联系方式 | 本阶段不直接设计公开策略 |

### 表单按钮

- 主按钮：提交待审核
- 次按钮：保存草稿
- 返回按钮：返回列表

### 发布说明

- 顶部提示：提交后不会立即公开，后续审核和联系方式展示策略需要单独确认。
- 联系方式提示：请不要填写身份证号、银行卡号、密码等敏感信息。
- 草稿提示：本地草稿只保存在当前设备或当前浏览环境，换设备可能看不到。

## BATCH-P3 建议

- UI 实现时优先使用本文案，不新增强承诺型文案。
- 如果页面空间不足，移动端优先保留标题、城市、分类、时间、地点、人数和提交状态。
- 联系方式相关文案在安全策略批准前只做提醒，不做公开展示承诺。
