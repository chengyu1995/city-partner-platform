## 老板使用方式

老板只需要在飞书发送需求或验收反馈，例如：

```text
新需求：……
验收反馈：/post 点不开
验收反馈：首页报 Internal Server Error
验收反馈：搭子列表样式不好看
```

项目总管会先判断是环境、路由、页面、交互、样式、数据还是代码问题，再自动执行修复和验证。
