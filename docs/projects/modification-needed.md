# 需要修改和补齐的内容

## 同城搭子网站需要修改

### 产品页面
- 首页需要进一步明确“同城搭子”定位和核心转化路径。
- `/partners` 需要完善筛选、卡片信息、空状态、城市和分类联动。
- `/post` 需要完善提交体验、草稿提示、待审核状态和字段校验。
- 登录页和个人中心存在 Next Link 规则 warning，需要后续单独修复。
- 当前还未接入完整真实数据库发布流程。

### 审核流程
- 目前待审核机制仍偏本地 MVP，需要后续接入正式审核队列。
- 联系方式展示策略需要单独审核，避免公开敏感信息。
- 需要建立“提交后不可直接公开，审核通过后才展示”的规则。

## 自动化系统仍需改进

### 仍不稳定点
- Codex 有时会倾向修改总管说明文档，而不是完成指定业务文档。
- 部分任务仍需要通过强制验收规则防止假成功。
- 任务去重会复用旧 payload，后续批次命名要避免使用旧失败批次。
- Worker 多开会导致任务领取混乱，需要保持单 Worker 运行。

### 后续补齐
- 增加任务看板状态查询命令。
- 增加每个团队单独飞书群或话题频道。
- 增加 QA 验收报告模板。
- 增加运营内容审核模板。
- 增加新项目接入模板。
