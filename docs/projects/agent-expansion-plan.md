# Agent 与团队扩展计划

## 新增员工 / Agent 的原则

新增 Agent 不能直接获得全部权限。  
必须先定义角色、职责、允许范围、禁止范围、验收标准，再接入飞书总管流程。

## 可新增角色

### 产品策划 Agent
负责需求整理、用户流程、信息架构，不直接改代码。

### UI/视觉 Agent
负责页面风格、组件建议、视觉规范，不直接提交业务代码。

### 前端开发 Agent
负责页面和交互实现，必须经过测试审核。

### 后端开发 Agent
负责 API、数据库、权限、数据安全，必须经过更严格审批。

### QA 审核 Agent
负责验收开发结果，输出问题清单。

### 运营 Agent
负责活动、内容、反馈、分类维护。

### 运维 Agent
负责腾讯云、PM2、环境、部署、安全检查。

## 经验积累机制

每次任务完成后，Agent 需要沉淀：
- 做了什么。
- 哪些规则有效。
- 哪些错误不能再犯。
- 哪些文件可复用。
- 哪些流程需要优化。
- 下一次同类任务应该怎么执行。

经验沉淀位置：
- docs/BATCH_LOG.md
- docs/ACCEPTANCE_LOG.md
- docs/TROUBLESHOOTING.md
- docs/projects/*.md

## 新项目接入规则

新项目接入时必须先创建：
- 项目说明文档。
- 团队分工文档。
- 当前状态文档。
- 下一步任务卡。
- 禁止范围。
- 验收标准。

项目总管必须先分类，再分发，不得默认把新项目当成同城搭子网站。
