# 运营团队加入计划

## 加入时机

运营团队不应在系统和核心产品流程不稳定时过早加入。  
建议在以下条件满足后加入：

1. 首页、浏览、发布、待审核流程稳定。
2. 测试审核团队流程跑通。
3. 联系方式展示策略明确。
4. 基础城市和分类可维护。
5. 后台或文档中已有内容审核规则。

## 运营团队职责

- 维护城市和分类内容。
- 设计首批冷启动活动。
- 收集用户反馈。
- 整理违规内容和审核建议。
- 设计搭子需求模板。
- 提供活动、话题和社群运营方案。

## 运营团队不做什么

- 不直接修改业务代码。
- 不直接改数据库。
- 不直接发布未经审核的联系方式。
- 不绕过项目总管给开发团队派活。

## 运营交付物

- 每周运营报告。
- 用户反馈清单。
- 分类调整建议。
- 活动方案。
- 内容审核问题清单。
- 下周运营计划。
